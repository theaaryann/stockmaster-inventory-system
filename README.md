
# StockMaster - Inventory Management System

StockMaster is a menu-driven Inventory Management System developed using C.

## Features
- Add Products
- View Products
- Search Products
- Update Products
- Delete Products
- Sell Products
- Low Stock Alert
- Calculate Total Inventory Value

## Technologies Used
- C Programming
- Structures
- Functions
- File Handling

## How to Run
1. Download main.c
2. Compile using GCC.
3. Run the program.
